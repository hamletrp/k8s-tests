# DevOps & SRE Skills Self-Assessment Checklist

Use this list to track and strengthen your expertise in DevOps and SRE disciplines.

## Foundational Skills
- [ ] Linux Fundamentals - shell scripting, networking tools, process mgmt
- [ ] Networking - DNS, TCP/IP, HTTP, firewall rules
- [ ] Programming/Scripting - Python, Bash, Go
- [ ] Version Control - Git, GitHub/GitLab

## Containers & Orchestration
- [ ] Docker - container creation, networking, optimization
- [ ] Kubernetes - deployments, services, Helm, RBAC
- [ ] Helm - Kubernetes package manager
- [ ] GitOps - ArgoCD, Kustomize

## CI/CD & Automation
- [ ] CI/CD Pipelines - GitHub Actions, GitLab CI, Jenkins
- [ ] Infrastructure as Code - Terraform, Pulumi
- [ ] Configuration Management - Ansible, Chef

## Cloud Platforms
- [ ] AWS / Azure / GCP - IAM, EC2, VPCs, EKS, GKE
- [ ] Cloud-native services - serverless, managed DBs

## Monitoring & Observability
- [ ] Prometheus + Grafana - metrics collection and dashboards
- [ ] Alertmanager / PagerDuty - alert routing
- [ ] Logging - Loki, Fluentd, ELK Stack

## Security & Compliance
- [ ] IAM / RBAC - access control policies
- [ ] Secret Management - Vault, External Secrets
- [ ] Container Security - image scanning, Kyverno, OPA

## SRE-Specific Skills
- [ ] SLIs / SLOs / SLAs - service level metrics and monitoring
- [ ] Error Budgeting - balancing reliability and velocity
- [ ] Incident Management - runbooks, RCA, postmortems
- [ ] Chaos Engineering - Gremlin, Chaos Mesh
- [ ] Capacity Planning - forecasting and autoscaling

## Soft Skills
- [ ] Collaboration - working across dev, QA, security
- [ ] Communication - incident response and docs
- [ ] Problem Solving - root cause analysis
- [ ] Documentation - internal wikis and runbooks
